# Security Policy

## Supported versions

Only the latest release receives security fixes. Update to it before
reporting.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/juanjoGonDev/devbar/security/advisories/new).

Include the DevBar version, your OS, the steps to reproduce, and the impact
you observed. You will get a reply within 7 days. Once a fix is released, the
advisory is published with credit to you unless you prefer otherwise.
